# Türkmenabat ERP v0.7 — Клиенты и продажи

## Добавлено

- карточки клиентов;
- магазины, дистрибьюторы, рестораны и другие покупатели;
- кредитный лимит;
- продажи и отгрузки;
- автоматическое списание готовой продукции;
- контроль складского остатка;
- продажи наличными и в долг;
- автоматическая оплата при продаже наличными;
- отдельная регистрация платежей;
- привязка платежа к отгрузке;
- дебиторская задолженность клиента;
- номер машины и водитель;
- адрес доставки;
- печатная товарная накладная;
- журнал продаж и оплат;
- аудит действий.

## Важное ограничение версии

Одна отгрузка сейчас содержит одну позицию товара. Модель базы уже поддерживает несколько
позиций, а экран многострочной накладной будет добавлен в следующем расширении.

## Установка

1. Распакуйте архив.
2. Загрузите содержимое в корень GitHub-репозитория с заменой файлов.
3. Нажмите Commit changes.
4. Дождитесь успешного Deploy на Render.
5. Откройте:
   - `/customers`
   - `/sales`

SQLAlchemy автоматически создаст таблицы:

- `customers`
- `sales`
- `sale_items`
- `customer_payments`

## Проверка

1. Создайте клиента.
2. Убедитесь, что на складе есть готовая продукция.
3. Проведите отгрузку.
4. Проверьте уменьшение остатка в `/finished-goods`.
5. Откройте накладную.
6. Зарегистрируйте оплату и проверьте задолженность клиента.

Следующий этап: финансы — касса, банк, расходы, доходы и задолженность поставщикам.
