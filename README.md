# Türkmenabat ERP v0.3 — Поставщики и закупки

Добавлено:

- справочник поставщиков;
- контактные данные и реквизиты;
- валюта поставщика;
- документ закупки сырья;
- автоматическое создание прихода на склад после проведения закупки;
- история закупок;
- расчёт суммы закупки;
- журнал аудита;
- новые пункты Dashboard.

## Обновление

Распакуйте архив и загрузите всё содержимое в корень GitHub-репозитория
`Turkmenabat-ERP` с заменой файлов.

Render автоматически создаст новые таблицы PostgreSQL при следующем Deploy.

## Проверка

1. Добавьте поставщика в `/suppliers`.
2. Убедитесь, что сырьё уже существует.
3. Создайте закупку в `/purchases`.
4. Проверьте, что остаток увеличился в `/warehouse/raw-materials`.
