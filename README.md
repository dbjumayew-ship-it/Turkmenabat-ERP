# Türkmenabat ERP v0.8 — Финансы

## Добавлено

- кассы и банковские счета;
- начальные остатки;
- приходные операции;
- расходные операции;
- контроль недостаточного остатка;
- категории расходов;
- привязка к клиентам и поставщикам;
- автоматическая регистрация оплаты клиента через финансы;
- дебиторская задолженность клиентов;
- кредиторская задолженность поставщикам;
- курсы USD и EUR к TMT;
- финансовый результат;
- журнал операций;
- печатные ПКО и РКО;
- аудит действий.

## Установка

1. Распакуйте архив.
2. Загрузите содержимое в корень GitHub-репозитория.
3. Разрешите замену файлов.
4. Нажмите Commit changes.
5. Дождитесь успешного Deploy на Render.
6. Откройте `/finance`.

При первом открытии автоматически создаются:
- Основная касса TMT;
- Расчётный счёт TMT;
- стандартные категории расходов.

SQLAlchemy создаст таблицы:
- `cash_accounts`
- `expense_categories`
- `finance_transactions`
- `exchange_rates`

## Проверка

1. Откройте `/finance`.
2. Создайте приход в кассу.
3. Создайте расход.
4. Проверьте остаток счёта.
5. Зарегистрируйте оплату от клиента.
6. Проверьте уменьшение дебиторской задолженности.
7. Откройте печатный документ.
