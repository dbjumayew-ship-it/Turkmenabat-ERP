# Türkmenabat ERP v0.6 — Контроль производства

В модуль «Производство» добавлен полный оперативный учёт отклонений.

## Добавлено

### Брак производства
- разбитые бутылки;
- неправильная крышка;
- повреждённая этикетка;
- неправильный уровень наполнения;
- утечка;
- грязная бутылка;
- повреждение упаковки;
- другие причины.

После проведения остаток готовой продукции уменьшается.

### Списание готовой продукции
- истёк срок годности;
- повреждение на складе;
- повреждение при погрузке;
- лабораторные образцы;
- другие причины.

### Потери сырья
- испарение спирта;
- потеря CO₂;
- пролив;
- потери при запуске линии;
- остаток в трубопроводах;
- промывка оборудования / CIP;
- повреждение сырья.

После проведения остаток сырья уменьшается.

### Передача в переработку
Готовая продукция списывается со склада и регистрируется как переданная в переработку.
Автоматический возврат спирта или сиропа не выполняется, поскольку фактический выход должен подтвердить технолог.

### Контроль качества
- привязка к производственной партии;
- крепость;
- CO₂;
- цвет;
- запах;
- вкус;
- статус: одобрено, условно одобрено или отклонено;
- лаборант/технолог;
- комментарий.

### История и статистика
- журнал всех операций;
- документ;
- дата и время;
- причина;
- ответственный;
- общий выпуск;
- брак;
- списание;
- переработка;
- расчёт эффективности;
- запись в аудит.

## Установка

1. Распакуйте архив.
2. Загрузите содержимое архива в корень GitHub-репозитория.
3. Разрешите замену существующих файлов.
4. Нажмите Commit changes.
5. Дождитесь статуса Live в Render.
6. Откройте:

`/production/control`

SQLAlchemy автоматически создаст таблицы:

- `production_events`
- `quality_control_records`

## Проверка

1. Убедитесь, что есть готовая продукция.
2. Оформите брак на несколько бутылок.
3. Проверьте уменьшение остатка в `/finished-goods`.
4. Оформите потерю сырья.
5. Проверьте уменьшение остатка в `/warehouse/raw-materials`.
6. Добавьте контроль качества для производственной партии.

Следующий этап: клиенты, продажи, отгрузки и автоматическое списание готовой продукции.
