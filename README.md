# Türkmenabat ERP v0.4 — Рецептуры

Добавлено:

- справочник готовой продукции;
- код и название продукта;
- объём одной единицы продукции;
- базовая партия;
- состав рецептуры;
- количество сырья на базовую партию;
- обновление существующего компонента;
- удаление компонента;
- журнал аудита;
- новый пункт меню «Рецептуры».

## Пример

Продукт:

- Код: ORG-033
- Название: Orange 0.33
- Объём: 0.33 л
- Базовая партия: 1000 бутылок

Рецептура на 1000 бутылок:

- Сахар — 18 кг
- Спирт — 85 л
- CO₂ — 12 кг
- Ароматизатор — 2.5 кг

## Установка

1. Распакуйте архив.
2. Загрузите содержимое в корень GitHub-репозитория с заменой файлов.
3. Выполните Commit.
4. Дождитесь успешного Deploy на Render.
5. Откройте `/recipes`.

SQLAlchemy автоматически создаст таблицы:

- `products`
- `recipe_items`

Следующий этап: производство с автоматическим расчётом и списанием сырья.
